# 指令与 Skill 评估

在准备换用新模型时，用一条命令评估全局协作指令和自己维护的全部 Skill。报告说明哪些做法值得保留、哪些需要调整，以及判断依据。评估入口自身也在覆盖范围内。

## 使用

```text
$agent-guidance-review
```

在要评估的模型下开始一个新会话，输入上面的命令即可。可以从其他项目调用。默认评估 `allurx/codex-dotfiles` 中的全局指令，以及 `allurx/agent-skills` 中现有和今后新增的 Skill。优先读取本地工作区；只有公开版本可读时，报告会标出版本和覆盖缺口。旧模型不可用时，仍可评估当前表现。

你会收到一份只读报告。它会对照你的原始目标，检查旧指令在新模型上是否仍然有用，也会保留已确认的偏好和授权边界。入口会在日常配置下检查任务表现，并尝试让同一模型在独立环境中复核旧稿。如果环境或模型身份无法验证，报告会说明这项限制，并给出其余已有证据支持的结论。判断方法和自评范围见 [Skill 说明](SKILL.md)。

## 安装

无需构建，安装源为完整的 `skills/agent-guidance-review/`。直接维护本地源码时，可将个人安装入口链接到这个目录；将两个维护仓库放在同一工作区，便于从任意项目定位本地版本。安装位置及复制安装方式见[仓库安装说明](https://github.com/allurx/agent-skills#安装)。
