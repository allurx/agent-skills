# 参数引导与默认值

本表提供引导主题与推荐值。用户选择逐项设置时，只问仍影响结果的缺失项；用户委托剩余参数或明确要求直接生成时，采用适配推荐并列入汇总。跳过不适用项，不能为完成整张表反复提问。

## 识别当前请求

| 用户表达 | 处理 |
|---|---|
| 只给人物姓名、角色名或人物参考图 | 确定目标人物，先问画风，然后继续未设置项 |
| 人物信息加若干参数 | 记录所有参数，只问缺失项 |
| “默认生成”“直接按默认出图”“其余你定并生成” | 保留显式设置，对所有剩余图像字段采用推荐值，汇总并生图 |
| “其余默认”“剩下你定” | 委托全部剩余字段；当前交付是图片且没有暂停要求时，汇总后生图 |
| “这一项默认”“选推荐”“跳过这一项” | 仅当前字段采用推荐值，继续询问后续字段 |
| “镜头都用推荐”“相机参数你定” | 仅镜头组采用推荐值，继续询问其他缺失组 |
| “继续”“好”“可以” | 若明确响应当前推荐选项，则仅接受当前选项；没有可对应选项则澄清，不能扩展为全部默认 |
| “直接生成”“别再问，出图” | 表示结束普通参数问答，保留已有设置并补全剩余视觉细节；只解决身份不明、硬性冲突或必要工具选择 |
| “把所有参数一次列出来” | 列出剩余适用字段和推荐值，使用稳定字段名或编号供一次选择；未选项仍待定 |
| “只给提示词”“先给方案，暂不生成” | 保持对应交付范围；默认授权只解决参数，不解除暂停 |
| “我改一下……” | 更新指明字段，仅重问受影响的冲突项 |

“默认生成”是指剩余参数交给推荐方案，不是把用户已经明确的场景、服装或数量全部重置。

## 角色身份与特殊缺失

用户提供的信息或参考图已能明确目标人物时，直接继续。存在同名角色时先问作品/版本；真人姓名有歧义时只补问区分目标所需的背景。仅提供照片时，以“参考图中的人物”继续，不根据面容猜测姓名，也不要求补充作品。缺少必要外观信息时，请用户简述发色、发型、代表性配色/饰品，或提供人物参考图。不要臆造人物资料。

用户明确将原创外观交给模型设计时，可以建立原创外观并在汇总中列出。原作角色应保留其标志性特征，年龄与外观按原作或用户明确指定的设定呈现。默认授权不意味着可以猜测同名角色指的是哪一位。

## 标准引导顺序

每行是一个主题，默认一轮一个问题；一条用户回复可解决多行。用户要求一次选择时改用完整面板。选项应随人物、用途和已有设置调整，不能机械照搬表内推荐。

| 顺序 / 字段 | 如何引导 | 明确授权默认时的推荐值 |
|---|---|---|
| 1 `render_style` 画风 | 写实写真、真人 COS、二次元插画；用户也可指定其他明确绘制风格 | 写实写真；明确要求角色扮演时采用真人 COS |
| 2 `realism` 写实程度，仅真人 | 纪实自然：动作/环境更像生活抓拍；自然写真：精致但保留环境差异；商业精修：更强调修饰与完整展示 | 纪实自然；二次元不适用 |
| 3 `identity_au` 人物身份 | 已有身份、日常设定或职业 AU；身份已明确则不重问 | 保留用户指定的身份或参考图中的造型，不从照片推断职业；原创人物按已有设定推荐适配身份与道具 |
| 4 `n` 数量 | 询问正整数数量，可建议 1、4、9 张；大组按实际工具能力分批 | 9 张 |
| 5 `scene` 场景范围 | 提供几个符合身份的公开/半公开地点；询问单一地点还是允许一组地点 | 与角色身份相符的一组公共活动地点 |
| 6 `outfit` 着装 | 给出配色、材质与服装结构选择；鞋履仅在可见时细化，标明是否允许换装 | 保留已指定造型，否则推荐一套符合人物配色、身份与年龄的完整服装；不默认换装 |
| 7 `action` 动作范围 | 根据场景提出 2–4 个有目的的动作，如转身取书、边收票据边迈步；允许一组自然动作 | 从身份/场景选择具体动作阶段，包含手部任务和重心；单图选一个，不默认交腿站姿 |
| 8 `expression` 表情范围 | 冷静专注、自然放松、温和微笑等；允许用户精确指定 | 与角色气质和正在做的事相符、克制自然的一种主表情 |
| 9 `framing` 景别 | 面部/半身/全身/多图混合，解释人物与环境占比 | 单图半身识别照；多图允许近景、中景、全身变化，不保证每张完整展示全身 |
| 10 `angle` 机位 | 平视、侧面三分之四、安全低机位、背面回头、玻璃反射等；可多图混用 | 以平视或侧面三分之四为主；多图允许少量安全机位变化 |
| 11 `focal_length` 焦段 | 24–35mm 更宽、更近；50mm 较自然；85–135mm 更有距离感；200mm 强远摄 | 单图 85mm；多图允许 50–135mm 变化，根据空间保留环境关系 |
| 12 `depth_of_field` 景深 | 背景明显虚化 / 适度虚化 / 环境清晰；可给 f 值作为视觉参考 | 纪实自然优先适度虚化、背景仍可辨，约 f/2.8–f/5.6 观感；其他模式按所选风格推荐 |
| 13 `obstruction` 前景遮挡 | 无遮挡 / 轻度 / 明显，说明可遮肩膀、包或部分鞋履；用户可要求完整展示 | 约 15%–35% 真实前景层次，允许部分主体遮挡，保留足够身份锚点，不仅装饰边缘 |
| 14 `camera_awareness` 发现镜头 | 完全不看镜头 / 少量注意镜头 / 全部看向镜头；允许 0–100% | 约 33%，按实际张数取整 |
| 15 `lighting` 时间与光线 | 白天窗光、室内环境灯、傍晚、雨夜街灯等；已知时间/天气不重问 | 与场景实际光源一致，允许脸部阴影、混合色温和衣物受光差异，不自动加脸部补光 |
| 16 `color_style` 色彩与质感 | 暖灰柔和 / 冷灰克制 / 自然清透等，结合真人或二次元表达 | 自然色彩与环境对比，克制修饰；颗粒与柔光只在适合所选风格时使用 |
| 17 `aspect_ratio` 画幅 | 3:4、4:5、9:16、1:1，用竖幅写真/手机壁纸等用途解释 | 每张独立图 3:4，多图各张相同；拼版整体比例另算 |
| 18 `layout` 交付形式 | n>1 时问独立图片，或独立图片加拼版；n=1 自动不适用 | 独立图片，不拼版 |

场景中的季节、天气和具体道具若会显著改变画面，而用户描述尚不明确，可作为当前主题的必要细化问题；无需把每件物品单独变成问卷。头像、剪影或局部构图中不呈现的身体动作、鞋履等标为不适用，不强行套用半身或全身默认。

不要额外要求用户设置内部 prompt 语言、模型调用参数名或参考文件标识。`语言=中文|英文|双语` 只在用户索要提示词或排版文案时控制文本交付，默认使用用户的对话语言。画面默认无文字。

## 参数组与自然语言映射

用户不必记字段名。支持原包常用写法：`写实写真`、`真人COS`、`二次元`、`写实程度=纪实自然|自然写真|商业精修`、`职业=...` / `AU=...`、`地点=...`、`服装=...`、`动作=...`、`表情=...`、`机位=...`、`焦段=...`、`光圈=...`、`画幅=...`、`发现镜头=...`、`layout=none|contact-sheet`、`n=...`。

- “镜头参数”组包括景别、机位、焦段、景深、遮挡与发现镜头；“画面风格”通常只解决画风/色彩，不自动决定场景、着装、动作或表情。
- “韩国 ins”“日系街拍”“电影长焦”“手机快拍”等先转为推荐视觉方向。只对语义明确的字段作赋值，不把标签当作对所有相机参数的默认授权。例如“手机快拍”可确定广角快拍方向，但不自动选定动作、服装或发现镜头比例。
- 若用户给出整组镜头预设且说明采用它，可以一次解决其中列明的镜头字段。提供预设时必须把实际涵盖的设置说清楚。
- 摄影距离由已选景别、焦段与场地共同确定；用户指定距离时纳入镜头约束。ISO、快门、白平衡或精确拍摄距离在用户要求精细摄影控制时才展开。不要把风格参考数字宣称为虚拟成片的实际 EXIF。
- 用户要求多张但只给单一动作/表情时，保持该动作/表情，通过允许的构图或瞬间变化区分；没有授权场景/服装变化就不能暗中扩展。
- “像真实抓拍”“别像 AI 精修图”可明确解决真人写实程度为纪实自然，但不能擅自覆盖已经选定的全身构图、浅景深或完整服装展示；在这些约束内改进动作、光线和材质。

## 默认值与依赖

推荐方案必须适应已经选定的内容。便利店门口应配门框、橱窗或货架反射，不放入办公室打印机；二次元应推荐相应绘制质感，不推荐真人皮肤毛孔；单图不沿用九张故事节奏。

光圈只作景深视觉参考，与主体距离、焦段和构图共同解释。面部清晰与前景虚化可以同时成立；不要在用户选择环境清晰时仍强制大光圈。纪实自然不会固定附加暖阳、均匀面部补光、极浅景深和全身完整；用户选择其中某项时照常落实该项，其余维度仍可自然。

发现镜头张数为 `k = floor(n × p / 100 + 0.5)`，其中 `p` 为 0–100 的百分比。例如：1 张、33% → 0 张；2 张、33% → 1 张；9 张、33% → 3 张。汇总写“k / n 张”，不承诺小数量无法满足的精确比例。用户要求 1 张“被发现”时以 1 张为准；明确给了百分比则按公式。张数和百分比互相冲突时只解决该冲突。

数量必须是正整数，百分比需在 0–100，画幅需可解释；无效或冲突数值先澄清，不静默截断。没有工具依据时不虚构 12 张上限。较大数量按已请求总量分批，说明实际进度；只有真实工具限制、时间或费用选择影响执行时才说明限制或请求决定。

## 拼版布局

仅在用户选择拼版时使用。最终交付包括 n 张独立原图和一张拼版，不用拼版替代原图。

| 数量 | 默认列 × 行 |
|---|---|
| 2 | 2 × 1 |
| 3 | 3 × 1 |
| 4 | 2 × 2 |
| 5–6 | 3 × 2 |
| 7–9 | 3 × 3 |
| 10–12 | 4 × 3 |

更多图片按用途选择接近方形的行列或分成多页，保持原图顺序与全部图数；用户已指定总图数时不为凑整改变数量。

不足的末行单元保持背景色并居中安排现有图片，不复制图片、不补生成凑数。间隔相对画布大小设置为细白或暖灰线，各格保留原图比例；拼版的整体比例与单图比例分开记录。用户明确指定行列数或版式时优先遵守，容纳不了所选数量时先解决冲突。

只有明确请求标题、编号或引语时才添加文字，此时补问缺失文案。`n=1 layout=contact-sheet` 时说明无需多图拼版，按一张独立图交付；若实际想要海报，则询问所需海报文案和排版。

## 单轮问法示意

目标人物已明确后：

> 我会逐项设置，可选推荐、自由描述，或随时说“其余默认并生成”。先选画风：写实写真（推荐）、真人 COS，还是二次元插画？

选择真人后问写实程度：

> 成片更偏哪种观感：纪实自然（推荐，保留环境光和动作中的不规整）、自然写真（稍精致），还是商业精修？

问表情时：

> 场景和动作已确定为雨夜便利店门口、手拿饮料。这张的表情选哪种：自然放松（推荐）、冷静专注，还是轻微微笑？也可以自己描述。

问焦段时：

> 镜头距离感选哪种：85mm 的远处写真感（推荐）、50mm 的自然视角，还是 28mm 的近距离手机感？

用户回复“85mm，4:5，剩下默认”后，记录焦段与画幅，再为其他未设置项应用适配推荐值，展示最终配置并生图；不要继续追问景深、遮挡等已被明确委托的字段。
