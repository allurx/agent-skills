# 视觉风格与分镜指南

本文件提供人物视觉转译、机位、动作与光线的候选方案。编写提示词和检查成片时读取适用部分；以下建议服从用户已选参数，不代表已验证的生图效果。

## 视觉目标与边界

- 真人写真与 COS 默认采用纪实自然的生活抓拍观感，以具体动作、普通环境光和可信空间关系建立真实感。
- 自然写真与商业精修保留为可选真人风格；二次元独立采用其绘制语言，不套用真人写实程度。
- 观察感来自构图；生成画面采用摆拍式创作，不据此声称真实人物已参与拍摄或同意，也不描述为真实非自愿偷拍。
- 人物可以是真实人物或虚构角色。年龄与外观按已有的人物资料、参考图或用户明确指定的设定呈现，服装、动作与构图须符合角色年龄。
- 默认使用公开或半公开场景与完整服装；其他显式选择按 [入口的创作范围](../SKILL.md#人物与创作范围) 判断，不把风格偏好扩大为内容禁令。

## 身份一致性

将已经确定的角色特征组织成 `IDENTITY_LOCK`，作为整组画面的共同依据：

- 角色身份：年龄设定、外观特征与身体比例。
- 脸部：脸型、眼型、眼色、眉形、鼻唇特征和整体气质。
- 头发：长度、颜色、刘海、束发方式及标志性发饰。
- 角色符号：代表性色彩、饰品、徽记或与场景相符的职业符号。
- 主服装：材质、轮廓、配色、鞋履和已确定的随身物。
- 画面基线：同一种渲染方式与已选风格；各场景的光照和局部材质表现随实际条件变化。

同组画面保持上述特征稳定；用户明确要求的变化应作为指定分镜的变化记录。
默认一套主服装，不擅自添加第二套服装、外套穿脱或下班换装。
表情和姿态可按参数变化，但不能借此改变脸型、年龄、发色或身份。
每张独立图像提示词都应包含必要的身份特征，不能只依赖上一张的文字描述。
身份参考只锁定人物与服装，不默认锁定首图的姿势、构图、光线或景深。
若后续画面反复沿用首图姿势，重新明确既定角色特征及当前指定的新动作，不继续照抄首图构图。
用户明确锁定动作、构图或光线时，保留该选择，不以增加变化为由覆盖。

## 真人写真与 COS 分支

保留已确定的人物外观与用户指定的造型，形成符合年龄设定的可信真人形象。角色 COS 另保留角色发型、代表性配色、服装结构与标志性饰品；普通真人写真不自动添加角色扮演设定。

- 头发表现遵循人物参考与已选造型；需要染发或假发时呈现可信材质。发束、碎发与受光随动作和环境变化，不固定每张都均匀透亮。
- 服装表现真实织物、合理缝线与受力褶皱，保留坐压、手握、包带压住衣物等有原因的局部变化。
- 饰品、文件、耳机和包具具有可信的尺度、重量及佩戴关系。
- 使用自然皮肤纹理和局部色泽差异、真实关节、合理重心与手部结构，不机械添加斑点或瑕疵。
- 避免动漫五官机械贴在真人身体上，以及塑料服装、蜡像皮肤和过度磨皮。

适用词汇：`photorealistic portrait`、`natural skin texture`、
`realistic hair strands`、`tailored fabric and natural folds`；用户选择 COS 时使用 `photorealistic cosplay`。
摄影参数在这里描述预期观感，不声称图像具有真实拍摄设备或 EXIF 数据。

### 真人写实程度：`realism`

仅在真人写真或 COS 模式下应用，具体选择服从主配置：

- **纪实自然（推荐默认）**：具体日常动作、普通且不均匀的环境光、适度可读的背景、自然材质与实际遮挡。
  人物可以局部处于阴影或运动中段，构图无需完整展示全身与服装；保留该张明确要求的关键内容。
- **自然写真**：允许更从容的构图、温和整理的服装和适度背景分离，仍保持可信动作、材质和环境光。
- **商业精修**：允许更精致的造型、突出人物的布光、受控浅景深与修饰，但仍保持空间、接触和反射关系正确。

纪实自然不能只靠叠加颗粒、模糊、降低分辨率、脏污、疲态或变老实现；其他模式也不把这些当作真实性捷径。
避免同时强制“脸始终清楚明亮、全身完整、衣服全可见、暖阳、极浅景深”，使每张都变成同一种商业姿势照。
用户确实指定其中某项时保留该项，用其余开放维度建立自然感。

### 真人空间与材质的统一

- 主体与背景共享可信的光源方向、明暗反差、色温及空气透视，不像清晰人物贴在过软背景上。
- 景深由焦距、距离和空间关系共同表现，处于相近深度的物体具有相近清晰程度。
- 脚底与地面、手与道具、包带与衣物等接触位置具有对应的投影、压痕或遮挡，不出现悬浮感。
- 褶皱、发束、反光和皮肤细节可以不规则，但应符合受力、材质与光线，不添加无原因的破损或污渍。
- 玻璃反射随视角、表面和实际环境出现，反射中的人物位置、遮挡与照明对应，不将玻璃默认画成无反射的透明层。
- 纪实自然允许树影落在衣物、脸或包上，允许环境让局部变暗，不自动补一束只照顾人物的理想光。

以上真人材质描述不进入二次元提示词；二次元只保留适合其画风的空间、受力与光影逻辑。

## 二次元分支

保留摄影式构图、观察距离、前景遮挡、环境光与动作设计，改用统一的二维人物绘制语言。以真人照片为参考时，保留用户指定的外观特征并转译为所选画风。

- 使用符合角色年龄设定的角色设计、清楚的线条、稳定的五官比例和一致的角色配色。
- 皮肤以绘画明暗和颜色过渡表现，不使用真人毛孔、实拍肤质或蜡像质感词。
- 头发以有层次的发束、线条与受光表现，不强制真实染发、发根或假发描述。
- 服装以准确结构、合理褶皱、绘画材质和清晰色块表现，不强制摄影级织物微距细节。
- 根据用户选择采用赛璐璐、柔和厚涂等方式；未指定时使用清晰线稿与克制的赛璐璐明暗。
- 长焦、景深和散景作为画面语言保留，避免加入与二维目标冲突的真人摄影质量词。

适用词汇：`anime character`、`consistent character design`、
`clean linework`、`controlled cel shading`、`cinematic composition`。
此分支不使用 `photorealistic portrait`、`photorealistic cosplay`、`same model` 或真人皮肤材质要求。
一致性表达使用“同一人物、同一面部设计、同一画风”。

## 职业与身份 AU

职业用于支持所选角色身份的情境和道具，不是强制把所有角色换成同一种制服。
优先采用已经确定的职业或日常身份；仅在职业 AU 已选定或相关身份已获默认授权，且符合角色年龄与设定时参考下列候选：

| 角色气质或能力 | 可选职业身份 |
| --- | --- |
| 冷静、精密、纪律型 | 运营主管、研究协调员、企业秘书、交通调度 |
| 守护、执行、行动型 | 应急响应、公共安全、现场协调 |
| 科技、游戏、机械型 | 技术支持、展会工作人员、机场运营 |
| 优雅、社交、情报型 | 画廊工作人员、品牌公关、公司职员 |
| 神秘、非人、未来型 | 档案管理员、设施运营、实验室协调员 |

道具须与所选身份及场景相符，不凭职业自行扩大到检查、治疗、安保管制等过程。

## 机位与构图候选

默认以 50–135mm 风格为主，85mm 是可选视觉锚点；用户指定广角、手机或其他镜头时按其选择。
纪实自然不默认极浅景深，背景保留与人物距离相符的结构；浅景深按指定参数或所选写真风格采用。
需要明显背景分离时可参考 f/1.8–f/2.8 的观感，但不能破坏空间连续性或用户要求保留的环境细节。

### 前景遮挡

通过门框、墙角、柱子、货架、植物、桌沿、椅背或窗框建立真实前景深度，而非只在画面边缘加装饰。
可参考约 15%–35% 的遮挡，较强时约 40%；比例不是指标。在用户允许遮挡主体时，让遮挡物实际挡住相应空间中的部分人物，而非机械停在边缘。
纪实自然允许合理遮住肩膀、包或鞋，允许运动中局部出画，不要求每张全身、双手与服装同时完整可见。
保留该张指定的主体信息；默认适度保留角色辨识度，用户要求背影、剪影、遮脸或完整全身时服从该构图。
用户选择无前景、边缘遮挡或完整服装展示时，不能将缺少主体遮挡判为失败或擅自修图。

### 远距离长焦

使用 85–200mm 风格表现空间压缩、前后景层次与公共场所中的观察距离。
人物可以偏离中心，但距离不能使角色辨识度或用户指定细节消失。

### 手机随手快拍

使用 24–35mm 等效视角、轻微倾斜、自动曝光感和少量边缘干扰。
高光可稍有溢出，但不默认严重失焦、低清晰度或监控画质。
只有采用混合镜头默认方案时才将其作为少量变化；用户指定整组手机感时贯穿整组。

### 安全低机位

可在桌面、椅面、台阶等高度利用 24–50mm 风格形成前景透视与人物动势。
镜头位于衣物外部，不朝向裙底、领口内部或其他衣物内部，不以低机位制造走光。

### 缝隙与反射

可通过公共空间的书架间隙、窗框、车窗或建筑物体之间构图。
玻璃、咖啡店窗户、电梯金属表面可加入轻微反光、重影与环境叠影。
遮挡和反射应服务于选定主体，不引入新的角色或让面部结构发生混淆。
纪实自然不自动消除玻璃上的环境反射；反射内容与强度遵守场景条件，不靠随意加污渍制造质感。

### 背面三分之四与坐姿

背面三分之四可表现行走或工作中的方向感；是否回头、露出侧脸由动作和表情参数决定。
坐姿可结合桌角、显示器、杯子或椅背建立前后景，姿态符合角色的工作或休息状态。
不要把姿态变化自动转为局部身体特写。

### 发现镜头

以侧眼、回头、短暂停顿等动作表现角色注意到摄影机，表情使用已经确定的情绪。
数量与比例完全采用主配置及其换算结果，本指南不固定发现镜头的比例。
用户要求不发现镜头时，不加入察觉、回头确认摄影者或被抓到的戏剧设定。
主动看向镜头与“发现摄影机”不是同一叙事；按所选意图区分。

## 动作与表情候选

只从用户允许的动作范围中选择；明确指定单一动作时，通过镜头变化丰富画面。
纪实自然优先描述“正在做什么、手接触什么、身体如何承重”，而不是只写站直、交腿或侧头的漂亮姿态。
在已选动作中表现中间状态：迈步时重心转移、取物时躯干与手臂协同、握物时手指真正接触物体。
衣物褶皱、包的摆动与支撑脚应响应同一个动作，不把多个互不相容的瞬间拼在同一姿态里。
可用的日常动作包括：

- 查看工作消息、文件、夹板、票据或屏幕。
- 整理发丝、耳机、袖口、证件牌或已指定的外套。
- 喝饮料、等待、排队、看站牌或短暂停留。
- 取文件、找门禁卡、伸手拿杯子、在货架旁取物。
- 在指定地点行走、靠栏杆休息、撑伞或抬手遮阳。

弯腰取物、坐姿和调整鞋履仅在符合所选动作与服装覆盖要求时使用，不作为必备卖点。
表情可采用专注、平静、放松、含蓄微笑、若有所思或克制警觉等符合角色的状态。
“自然抓拍”描述动作处于过程之中，不等于人物不知情或未经同意。
不因增加张数擅自添加恐惧、羞辱、挑逗、同事互动或新的情绪发展。

## 场景候选

已确定地点是场景边界；用户只选一个地点时，默认在该地点内部变化构图。
开放候选包括写字楼大厅、公共打印区、开放办公区、商场、公共走廊、书店、咖啡店、
展览馆、酒店大厅、车站公共区、街角、公园、天桥、公交站与建筑公共出口。
非公开控制室、管制通道等不能仅凭“职业 AU”自动视为公共区并添加。
医疗场所仅可采用不涉及患者隐私的前台等公共工作环境，不加入检查或治疗过程。

## 光线与色彩

- 办公公共区：中性或冷白顶灯，可搭配克制的屏幕光。
- 咖啡店、酒店大厅：暖色实际光源与柔和阴影。
- 商场、车站：顶灯、灯箱及玻璃反射。
- 阴天、窗边：柔和散射光与低反差层次。
- 傍晚、夜街：路灯、橱窗、车灯散景；雨后反射仅在雨天场景被允许时使用。

真人纪实自然采用场景本来的光照分布与自然颜色，不预设暖阳、人物补光、柔焦、颗粒或暗角。
阴影由树冠、建筑、窗框或实际灯具造成；允许人物不均匀受光，避免为突出脸而破坏场景照明逻辑。
自然写真可采用柔和高光与温和调色；商业精修可按选择使用 bloom / halation、细颗粒和暗角。
二次元采用所选绘制方式表达同一光源和空间关系，不添加真人皮肤、实拍瑕疵等材质词。
不默认强 HDR、过度锐化或浓重赛博霓虹；用户明确选择相应视觉风格时可调整。
韩系、日系等风格标签应与具体光线、颜色和材质描述结合，不擅自改变角色面部身份。

## 成套分镜的变化方式

数量遵守已确定的正整数 `n`；每张都是独立图片，维持已确定的地点、服装、动作和情绪范围。
优先变化用户开放的维度：景别、距离、方向、前景物体、镜头焦段、反射或光线。
用户锁定的维度不参与随机变化，不为避免重复而覆盖其选择。

可选分镜功能包括角色识别、环境建立、动作中景、侧面或背面三分之四、面部近景、
坐姿状态、特殊前景、远距离长焦与收束构图。这些是候选功能，不是强制的九张顺序。
夜间离场、通勤、休息或下班换景仅在参数允许时采用，不自动扩展为角色的一天。
`n=1` 优先完整表达所选参数；较多画面在可变维度内分配差异，不强行增加剧情。

构图服从已确定的画幅与每张关注点；合理的局部遮挡或动作出画可以保留，不自动补成完整展示图。
真人纪实自然检查动作受力、环境光来源、材质变化、前景实际遮挡、接触阴影与反射是否共同可信。
若仍有摆拍感，优先修正动作和空间关系，不继续叠加模糊、颗粒或重复引用同一首图姿势。
身份、年龄、服装和场景按已确认配置检查；发现镜头数量和具体风格同样服从实际选择。
