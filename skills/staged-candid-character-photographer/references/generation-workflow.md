# 生成、检查与恢复

在参数齐备且当前请求允许生图时执行。生成或编辑前核对实际工具说明，不假定所有环境都支持相同工具名、seed、精确尺寸或参考方式。

默认新图的 `target_size` 留空，按已定画幅构图并使用工具的自动尺寸，不因当前入口缺少精确宽高参数而阻塞。只有用户明确设置精确像素时，才核对当前入口实际开放的控制方式及支持范围，例如 `size`、宽高参数或文档明确的尺寸选项；没有两个独立的宽高参数不等于不能指定尺寸，公开 API 支持也不等于当前入口已开放。此时仅写提示词不构成精确输出能力证明；入口不支持或无法确认时，说明具体阻塞，不擅自取消精确要求或切换服务。内置通道的自动尺寸与已知限制见 [使用说明的注意事项](../README.md#注意事项)。

新图默认每张只进行一次生图调用，画幅、画质及另行明确的像素规格都须由这次直接输出满足；自动尺寸不额外要求 1440 × 2560 或固定为 941 × 1672，也不通过缩放、裁切、补边、超分、扩图或第二次生成凑尺寸。用户明确要求处理已有图片时，按下文 [尺寸处理与保真](#尺寸处理与保真) 执行；后续另行授权的修复或重试与首次结果分别记录，不能倒述为首次已合格。

## 准备生成

使用参考图前查看实际内容，遵守工具对本地路径、会话图片和参考数量的要求。身份参考默认只维持用户指定的人物特征，其原始宽高比不决定新图画幅；只有用户要求复刻时才锁定姿势、光线和构图。不能据未查看的文件名推断其内容。

将参数转换为两层，详细视觉条件见 [视觉指南](visual-style.md)：

- `IDENTITY_LOCK`：人物与年龄设定、脸部/头发/标志性符号、主服装、比例和画风；用户明确要求变化的项按各图记录。
- `SHOT_PLAN`：本张地点、动作瞬间、可见的手部接触与重心支撑、衣料受力、表情/视线、光源、机位、景别与焦平面、前景及允许的裁切。用这些关系约束细节尺度，避免把彼此不相容的姿态、褶皱、光影和清晰度拼在一起。

每张请求携带必要的身份锚点及当前分镜。生成前核对请求中的数量、画幅与目标尺寸同当前配置一致，从分镜阶段就按已确定的比例构图，测试请求也不擅自改用其他规格。变化只发生在用户允许的范围内：单一地点不展开为多个地点，单一动作/表情不自动增加剧情，普通真人写真不自动变成 COS。

`n` 表示最终独立图片数量。每张请求明确单图、单场景、指定主体；默认无拼格、排版文字和水印，用户明确要求的文字或标志按其要求处理。不要把整组分镜交给模型生成一张多格图，也不要机械粘贴不适用的长串负面词。

发现镜头张数按 [参数引导](parameter-guide.md#默认值与依赖) 换算并分配；主动看镜头和偶然发现摄影机按用户叙事区分。摄影数值用于描述预期观感，不声称是实际拍摄或 EXIF 数据。

## 调用与进度

1. 先生成第一张，读取直接返回文件的尺寸，核对画幅及另行明确的像素规格，并按 [分层验收](#视觉检查与修正) 检查画质，通过后再继续。首图占用 `n` 中的一个图号，通过验收才计入完成数量，不擅自新增样张确认轮次。
2. 后续逐张生成，按工具允许的方式引用已检查的首图或用户参考图。明确哪些特征保持、哪些采用当前 `SHOT_PLAN`，避免复制首图姿势。无参考能力时重复必要锚点并说明一致性限制，不承诺完全同脸。
3. 每次调用都记录图号、当前配置、调用状态及实际返回的图片或文件标识。区分未开始、执行中、已返回待检查、已完成、失败；未返回结果或只有提示词不算已生成，未检查的图不算已验收。新图一次直接输出通过画幅和视觉检查，且满足另行明确的像素规格后，才计为已完成。
4. 画幅与已设置的目标尺寸按工具实际支持的方式传递；取得图片后、作为成品展示或提供下载前，读取实际文件的宽高像素。自动尺寸按 [画幅与目标尺寸](parameter-guide.md#画幅与目标尺寸) 容许整数像素取整的微小比例误差，报告近似比例；仅在 `target_size` 已设置时做精确像素比对。无法读取时保留待检查状态，不从提示词、预览或文件名推定达标。交付前确认文件存在、可打开且属于本任务；画幅明显偏离、已定像素规格不符或视觉不合格时报告未完成，不能自动转入尺寸处理分支。
5. 长任务保持可观察进度。用户中途修改时停下尚未开始的旧分镜，对执行中的调用按工具支持情况处理；不假称已经取消，也不自动把旧配置结果计为满足新要求。

不要在已有调用仍执行时重复发起同一张请求。等待、轮询及展示使用工具要求的方式，不用“正在生成”文字代替真实调用。工具若自动展示生成结果，将其视为待验收预览，继续完成检查，不能因图片已显示就宣布完成。

## 尺寸处理与保真

本节仅用于用户明确要求的已有图尺寸调整、超分或扩图，不是新图一次生成要求的后备方案。新图返回了文件不等于获得已有图处理授权；“高画质”“符合质量要求”本身也不授权生成后再加工。用户确有额外处理要求时按其范围执行，工具或宿主对编辑方式的限制仍适用。

目标尺寸、处理前的原图尺寸与处理后的交付尺寸分别记录，不把处理后的文件称为原生高分辨率。基础图有人体结构、材质、接触或空间等明显错误时先按获准的修正规则处理，不用超分或缩小显示掩盖问题。保留原图，调整结果另存，避免覆盖可回退的来源。

按用户想保留或改变的内容选择处理方式：

| 目的 | 处理方式与边界 |
|---|---|
| 保留取景，仅改变像素尺寸 | 普通等比缩放改变采样，不恢复原图未包含的真实细节；缩小或只要求尺寸适配时可用 |
| 保留取景，提高尺寸并增强细节 | 有可用能力时采用保守 AI 超分；补出的细节包含推测，不能宣称还原了真实细节或变成原生高清图 |
| 增加画面外围内容、扩大取景或调整画幅 | 按用户允许的范围扩图；扩图会新增内容，不作为单纯提高分辨率的默认步骤 |

原图已接近目标比例、用户要求保留构图并提高细节时，优先保守超分，再按需微调到精确尺寸。微调不能拉伸人物或损失关键内容；比例差异会明显改变取景或与用户限制冲突、且处理方式尚未明确时，说明裁切、留边或扩图的影响，只解决这一项。已有明确选择时直接执行。

用户要求不重绘、保留原有细节时，不默认使用 AI 超分或扩图；“只改尺寸”不等于允许改变人物比例。所需处理能力不可用或结果仍未达标时，保留原图用于恢复，明确任务未完成及阻塞原因，不将原图作为成品交付或计入完成数量。用户明确索要未达标原图时可作为草稿提供，附实际尺寸与未完成状态；只有用户明确更改规格后才能按新规格验收。不用普通放大冒充 AI 超分，也不为凑尺寸反复重生成。

任何尺寸处理后重新读取交付文件的实际宽高，并完成下节的处理后复核。尺寸达标与视觉保真分别验收，增强不能突破视觉指南中的细节尺度，修正与重试沿用同一张图的既有额度。

## 视觉检查与修正

对实际文件分层检查，真人全部风格使用同一摄影真实性标准，二次元使用视觉指南中的绘制标准：

1. **整体观感**：在整图和预期观看尺寸下核对人物、年龄、服装、构图与风格，检查人体比例、透视、光线及主体与背景的关系；商业精修仍应像可信的摄影，不能用磨皮或背景糊化掩盖贴图感。
2. **原尺寸关键局部**：查看文件原尺寸下的脸与五官、可见手部与道具接触、身体支撑、衣料受力、接触阴影和反射，核对焦平面与细节尺度。只检查实际可见且足以判断的内容，不把远景或合理失焦中无法分辨的纹理当成缺陷；关键局部因预览受限无法核验时保留待检查状态。
3. **尺寸处理后复核**：重新核对最终文件宽高，以整体和原尺寸局部对照处理前图，检查脸型、五官、年龄、身体比例、发丝、衣料和道具是否变化，排查过度锐化、虚构纹理、失焦处不合理变清晰与构图损失。未经尺寸处理的图此层不适用。

明显的人体结构、材质、贴图感、手部接触、空间或反射错误，以及本应清晰的主体明显模糊，均属于质量不合格，不能按小瑕疵验收，也不能因像素尺寸正确而放行。新图一次生成未通过时报告未完成；已有明确修复授权时才在相应范围与额度内修正。只有不影响核心选择和基础可信度的小瑕疵才先说明、询问是否值得修复。修正定位具体动作、光源、材质或参考约束，不只叠加“更真实”“更多毛孔”。

跨图只在允许变化的维度检查重复；用户选定全身完整、无前景、固定站姿或商业精修时，相应特征不是缺陷。

新图默认的一次生图要求不含自动重试或生成式修正，尺寸、质量不合格或调用报错都不自动增加调用。仅在用户已允许重试的任务中，同一图最多额外自动尝试一次，包括必要修正或可恢复的临时错误。遇到工具明示禁止重试、内容限制、需要新增费用/服务或无法确认前一次状态时，不自动重试。不要绕过限制或擅自切换服务。

## 效果验证与结论边界

以下用于评估 Skill 或比较生成效果，不随普通生图或文档维护自动增加样图、盲评或向检测服务上传图片：

- 文档校验、提示词检查和行为推演只能证明规则结构与决策路径，不能证明成片更像摄影。要报告拟真改善，应在相同人物参考、场景、风格、输入约束和可控的工具设置下，取得新旧规则的多张实际样图，保留失败样本及无法固定的条件；统一显示尺寸与处理方式，随机排序并隐藏版本进行盲评，记录评价人数、样本范围与结果。要评估与真实摄影能否区分，还需加入来源已知、题材相近的真实照片对照，隐藏来源标签，不能只比较两组生成图就作此结论。
- 视觉可信度、机器检测结果与生成来源分别报告。引用检测结果时记录检测器名称、版本、判定阈值、样本及预处理范围，并用同类真实照片建立误报基线；无法取得的项标为未披露，限制结论。未经实际检测不宣称通过，单个检测器的判定也不能证明相机实拍或代表所有机器与人眼。

检测评估的适用范围与误报考虑见 [NIST AI 100-4，第 4.2.2、4.3 节](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-4.pdf)；这里据此限定证据，不把该报告当作本 Skill 的效果认证。

## 失败与继续

新图一次生成未通过、错误无法就地解决或获准的额外尝试仍失败时，暂停未开始队列，仅交付已通过全部验收的图片，并按实际状态报告已完成、待检查、失败和未开始的张数。保留配置、分镜编号、参考来源、已返回产物及已用调用次数。

恢复时先核对上一轮调用是否仍执行以及已有产物是否可用，再从待检查或首个未完成项继续。没有产物证据的历史提示词、预定路径或其他任务旧图不能充当已完成图片。普通“继续”不会重置已用调用次数；一次生成已经失败时，须由用户明确要求再次尝试，外部条件改变本身不追加调用授权。已获准重试的其他任务仍按剩余额度恢复。

已完成图片缺少可用文件或参考无法再访问时，说明具体缺失；工具需要重附参考时请用户重新提供，不虚构路径，不默默重做成功项。

## 排版与交付

用户选择拼版时，先取得全部已验收的独立成片，再按参数指南的布局使用当前可用且获准的排版能力。保留单图，各图只使用一次，裁切保留脸、手及用户指定的关键内容；不复制图片补齐空格，也不多生成图片凑数。

只有用户要求时添加标题、编号或文案。排版能力不可用或失败时先展示已验收单图，明确拼版未完成；不把排版说明当作已合成产物。最终展示、下载与完成声明须对应同一份已验收文件；新图交付直接生成且尺寸、画质均合格的成片，用户明确要求已有图处理时才交付相应处理结果。说明实测宽高像素与比例、实际调用次数，以及人物一致性等实际限制；另有获准的缩放、超分、裁切或扩图时如实说明。拼版也须核验其单独设置的规格。未核验或未达标时报告未完成，不能用附带差异说明代替验收。
