# 引导式角色摄影师

从人物姓名、角色名或人物参考图开始，引导选择摄影参数，汇总后生成图片。支持写实写真、真人 COS 和二次元人像；真人各风格共用严格的摄影真实性要求，构图按用途、动作和场地适配。

## 使用

调用本 Skill 后提供人物姓名、角色名或人物参考图，例如：

```text
2B
```

模型会先询问缺失的画风，真人模式再选择纪实自然、自然写真或商业精修的修饰与叙事风格，然后引导身份、数量、场景、着装、动作、表情和镜头等设置。既有 `realism` 和 `写实程度=...` 写法继续有效，这些选项不代表真实性高低。每次可选择推荐、自己描述，也可说“把剩余参数一次列出来”集中选择；已经给出或委托决定的项目不会重复询问。

随时可以缩短流程：

```text
这项用推荐。
```

只接受当前项，继续问下一项。

```text
场景改为雨夜便利店门口，其他已经选好的保留。
```

只修改相关参数，必要时解决受影响项。

```text
镜头参数你定，其他继续问我。
```

只委托镜头组，继续设置其他缺失项目。

```text
其余默认并生成。
```

保留现有选择，补齐剩余项，汇总并生图。

也可以一开始直接生成：

```text
2B 真人COS n=4 地点=写字楼公共大厅，按默认生成。
```

上例生成 4 张真人 COS 图片，地点限定为写字楼公共大厅。新图未设置且已委托默认的数量、画幅与目标尺寸采用 1 张、9:16、1440×2560，无需指定抖音等用途；用户明确指定多张时按指定数量执行。其他未设置且已委托的项目可采用纪实自然、保留已有身份或参考图造型，景别、焦段和前景则按动作、场地退距及人物与环境关系推荐。

参数按“本轮明确要求 → 当前任务已确定的设置 → Skill 默认”的顺序确定，默认只填空。“按默认测试”也继承已有参数，不重置已选画幅或尺寸。身份参考图的方形比例不决定新图画幅；仅对已有图片做局部编辑、未要求改尺寸时，则保留原图比例与尺寸。

“直接生成”会保留已有选择并补齐普通视觉细节。需要先审阅时说“先给我汇总，等我确认再生成”；只想要文字时说“只要提示词，不生图”。

## 减少不真实感

真人各风格都以尽可能接近真实摄影为质量目标，将动作、手部接触、重心、衣料受力、光源与景深安排为一致的具体条件。皮肤、发丝与织物细节遵守景别、人物占比、光线及景深，远景或失焦部位不会机械补成微距纹理。人物身份用 `IDENTITY_LOCK` 记录，每张动作与构图用 `SHOT_PLAN` 记录；具体规则见 [视觉指南](references/visual-style.md)。

验收分别检查整体摄影观感、原尺寸关键局部，以及尺寸处理后的保真。明显的人体、接触、材质、空间或反射错误不能作为合格成片或靠超分掩盖，按 [生成与恢复](references/generation-workflow.md) 的有界规则修正；不影响基础可信度的小瑕疵先询问是否修复。显式选择的构图、姿态与精修风格继续保留。

摄影观感、检测器结果与生成来源分别判断，不保证任何人或机器都无法识别，也不把生成图称为已证实的相机实拍。文档校验与行为推演不证明画质改进，仍需同条件实际样图对照与盲评；机器检测须记录检测器、版本、样本和误报基线。修改 Skill 不自动启动额外生图或外部上传，验证细则见生成与恢复指南。

## 图像与工具

真正出图需要运行环境提供可用的图像生成能力。此包提供对话和生成工作流，不内置模型、API 凭据、付费服务或安装器。

画幅与像素尺寸分别记录，新图默认对应 `画幅=9:16，尺寸=1440×2560`，均可显式覆盖。用户改画幅时，来自默认或自动推导的目标尺寸随之调整；只改尺寸时，默认或推导的画幅也随之更新，汇总说明兼容的新设置。只有两个仍有效的显式画幅与尺寸互相冲突时才澄清，不机械保留旧默认值。

1440×2560 是最终交付目标，不是平台硬性标准，也不保证工具原生输出该尺寸。生成前核对实际工具能力，交付时分别核验目标尺寸、原图尺寸和处理后尺寸；不能仅凭提示词宣布达标。

已有清晰的 1080×1920 图片无需仅为凑尺寸放大。基础图验收后，再判断是否需要保留取景的超分放大，或向画外补内容的扩图；保守增强仍须保持细节尺度，处理后重新检查人物与关键关系。具体处理边界见 [生成与恢复](references/generation-workflow.md)。

多图先完成独立图片，再按用户选择合成拼版。人物一致性优先使用可用的角色参考能力，不能保证所有模型都能做到完全同脸。工具缺失、部分失败或画幅不支持时会说明实际完成范围。

支持真实人物、公众人物、虚构角色和人物参考图。年龄与外观遵循原作、已有资料、参考图或用户明确指定的设定，不自动改为成年 AU。默认采用完整服装及公开或半公开场景；其他显式选择依实际内容规则处理。

## 文件

- `SKILL.md`：入口、交互状态、授权与汇总条件。
- `references/parameter-guide.md`：逐项参数、默认授权、自然语言映射与拼版布局。
- `references/visual-style.md`：角色一致性、真人/二次元、摄影与分镜规则。
- `references/generation-workflow.md`：生图、产物检查、有界重试与恢复。
- `examples/usage-examples.md`：跨轮选择、默认生成与失败分支示例。
- `agents/openai.yaml`：可选的界面展示信息与起始提示。
- `manifest.txt`：文件清单。

使用时保留完整目录；只复制 `SKILL.md` 会丢失其引用的参数与执行规则。
