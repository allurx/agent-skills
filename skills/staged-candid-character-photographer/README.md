# 引导式角色摄影师

从人物姓名、角色名或人物参考图开始，引导选择摄影参数，汇总后生成图片。保留电影化观察式构图，支持写实写真、真人 COS 和二次元人像。

## 使用

调用本 Skill 后提供人物姓名、角色名或人物参考图，例如：

```text
2B
```

模型会先询问缺失的画风，真人模式再询问写实程度，然后引导身份、数量、场景、着装、动作、表情和镜头等设置。每次可选择推荐、自己描述，也可说“把剩余参数一次列出来”集中选择；已经给出或委托决定的项目不会重复询问。

随时可以缩短流程：

```text
这项用推荐。
```

只接受当前项，继续问下一项。

```text
场景改为雨夜便利店门口，其他已经选好的保留。
```

只修改相关参数，必要时解决受影响项。

```text
镜头参数你定，其他继续问我。
```

只委托镜头组，继续设置其他缺失项目。

```text
其余默认并生成。
```

保留现有选择，补齐剩余项，汇总并生图。

也可以一开始直接生成：

```text
2B 真人COS n=4 地点=写字楼公共大厅，按默认生成。
```

上例生成 4 张真人 COS 图片，地点限定为写字楼公共大厅。用户指定的参数优先，只有未设置且已委托的项目才采用推荐值：9 张独立图片、每张 3:4、纪实自然的写实写真，保留已有身份或参考图中的造型，以中长焦和可辨认的环境层次为主。

“直接生成”会保留已有选择并补齐普通视觉细节。需要先审阅时说“先给我汇总，等我确认再生成”；只想要文字时说“只要提示词，不生图”。

## 减少不真实感

纪实自然模式把真实性落实到有目的的动作、合理重心、普通环境光、受力褶皱、前景实际遮挡和主体/背景的质感一致。不会每张同时要求脸部均匀明亮、全身完整、服装全部展示、暖阳和极浅景深，也不会只靠噪点、模糊或“毛孔”词修补。

人物参考与每张的动作/构图分开记录，维持角色身份时不默认复制首图姿势。生成后会检查姿势重复、装饰性遮挡、贴图感与反射问题。用户明确要求全身完整、固定姿态或精修风格时按其选择检查，小瑕疵先询问是否修复。

## 图像与工具

真正出图需要运行环境提供可用的图像生成能力。此包提供对话和生成工作流，不内置模型、API 凭据、付费服务或安装器。

多图先完成独立图片，再按用户选择合成拼版。人物一致性优先使用可用的角色参考能力，不能保证所有模型都能做到完全同脸。工具缺失、部分失败或画幅不支持时会说明实际完成范围。

支持真实人物、公众人物、虚构角色和人物参考图。年龄与外观遵循原作、已有资料、参考图或用户明确指定的设定，不自动改为成年 AU。默认采用完整服装及公开或半公开场景；其他显式选择依实际内容规则处理。

## 文件

- `SKILL.md`：入口、交互状态、授权与汇总条件。
- `references/parameter-guide.md`：逐项参数、默认授权、自然语言映射与拼版布局。
- `references/visual-style.md`：角色一致性、真人/二次元、摄影与分镜规则。
- `references/generation-workflow.md`：生图、产物检查、有界重试与恢复。
- `examples/usage-examples.md`：跨轮选择、默认生成与失败分支示例。
- `agents/openai.yaml`：可选的界面展示信息与起始提示。
- `manifest.txt`：文件清单。

使用时保留完整目录；只复制 `SKILL.md` 会丢失其引用的参数与执行规则。
