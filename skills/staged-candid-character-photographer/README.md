# 引导式角色摄影师

从角色名开始，一次询问一个摄影主题；参数设置完毕后，展示汇总并实际生成图片。沿用 `staged-candid-character-photographer` 名称，保留电影化观察式构图；真人模式增加纪实自然、自然写真和商业精修的选择。

## 使用

调用本 Skill 后输入角色名，例如：

```text
2B
```

模型会先询问画风，真人模式再询问写实程度，然后依次引导身份、数量、场景、着装、动作、表情和镜头等设置。每次可选择推荐、自己描述，也可在一条回复中提供多个参数；已经给出的项目不会重复询问。

随时可以缩短流程：

```text
这项用推荐。
```

只接受当前项，继续问下一项。

```text
场景改为雨夜便利店门口，其他已经选好的保留。
```

只修改相关参数，必要时解决受影响项。

```text
镜头参数你定，其他继续问我。
```

只委托镜头组，继续设置其他缺失项目。

```text
其余默认并生成。
```

保留现有选择，补齐剩余项，汇总并生图。

也可以一开始直接生成：

```text
2B 真人COS n=4 地点=写字楼公共大厅，按默认生成。
```

默认是 9 张独立图片、每张 3:4、成年职业 AU、真人 COS 的纪实自然观感，以中长焦和可辨认的环境层次为主。用户显式参数优先。需要先审阅时，明确说“设置完成后先给我汇总，等我确认再生成”；只想要文字时说“只要提示词，不生图”。

## 减少不真实感

纪实自然模式把真实性落实到有目的的动作、合理重心、普通环境光、受力褶皱、前景实际遮挡和主体/背景的质感一致。不会每张同时要求脸部均匀明亮、全身完整、服装全部展示、暖阳和极浅景深，也不会只靠噪点、模糊或“毛孔”词修补。

人物参考与每张的动作/构图分开记录，维持角色身份时不默认复制首图姿势。生成后会检查姿势重复、装饰性遮挡、贴图感与反射问题。用户明确要求全身完整、固定姿态或精修风格时仍按选择执行。这些规则来自用户提供的成片复盘，不代表本包已经对原始参考图或新成图进行视觉验证。

## 图像与工具

真正出图需要运行环境提供可用的图像生成能力。此包提供对话和生成工作流，不内置模型、API 凭据、付费服务或安装器。

多图先完成独立图片，再按用户选择合成拼版。人物一致性优先使用可用的角色参考能力，不能保证所有模型都能做到完全同脸。工具缺失、部分失败或画幅不支持时会说明实际完成范围。

仅支持明确成年虚构角色、完整服装及公开或半公开场景。需要成年化时采用 25 岁以上的成年 AU；不接收真人照片或真实人物的此类造型任务。

## 文件

- `SKILL.md`：入口、交互状态、完成条件与实际生图流程。
- `references/parameter-guide.md`：逐项参数、默认授权、自然语言映射与拼版布局。
- `references/visual-style.md`：角色一致性、真人/二次元、摄影与分镜规则。
- `examples/usage-examples.md`：跨轮选择、默认生成与失败分支示例。
- `agents/openai.yaml`：可选的界面展示信息与起始提示。
- `manifest.txt`：文件清单。

使用时保留这些相对目录；只复制 `SKILL.md` 会丢失其引用的参数与视觉规则。压缩包沿用原包的布局，`SKILL.md` 位于根目录；是否接受 ZIP 导入取决于运行环境。此交付没有安装或覆盖现有 Skill。
