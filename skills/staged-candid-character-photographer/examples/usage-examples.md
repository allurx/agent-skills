# 调用示例

以下是对话行为示意，不是预先替用户完成的选择。真实执行时，每次只提出当前问题并等待回复。

## 1. 角色名开始逐项引导

用户已经调用本 Skill，输入：

```text
2B
```

助手：

```text
我会逐项设置，可选推荐、自由描述，或随时说“其余默认并生成”。先选画风：真人 COS 写真（推荐），还是二次元插画？
```

用户：

```text
二次元，4张，只在雨夜便利店门口，穿黑色风衣。
```

助手记录画风、数量、场景、时间/天气及风衣选择；不要重复询问这些已明确的内容。接下来确认人物身份；若原作身份已明确且适用，则跳过此项。之后着装只补充用户未指明且影响外观的细节，动作、表情等仍依次询问。

## 2. 单项推荐不跳过后续问题

当前正在问表情：自然放松（推荐）/ 冷静专注 / 轻微微笑。

用户：

```text
推荐的。
```

助手只把表情记为自然放松，继续问下一个未设置主题，不生成图片，不把其他字段标为默认授权。

## 3. 委托镜头组，保留其他待选项

用户：

```text
镜头全用推荐，着装我想自己选。
```

助手根据已有场景和动作解决景别、机位、焦段、景深、遮挡及发现镜头，其他字段不被默认授权覆盖。着装尚未解决时，下一问给出适配的服装选择。

## 4. 参数齐备，汇总后直接生图

已经确定角色、画风、职业、数量、场景、着装、动作和表情，用户继续说：

```text
镜头用85mm平视半身，浅景深，门框遮挡20%，都不要看镜头，其他默认并生成。
```

助手保留全部明确设置，解决剩余字段；汇总包含发现镜头 0/n 张。随后实际调用生图工具，不再询问是否确认，不输出一大组提示词后结束。

若 n=4，则得到四张用户所选场景内的独立图，不能因为数量增加就自行加入新的地点或服装。

## 5. 从开始就使用默认

```text
约尔·福杰，二次元，n=1，表情=轻微微笑，画幅=4:5，按默认生成。
```

保留二次元、单张、微笑、4:5；仅未指定项采用适配推荐。汇总中写明单图采用的一个具体场景和动作，而不是列出一整套地点。默认 33% 取整后是 0/1 张发现镜头；若用户另说“看向镜头”，则改为 1/1。二次元请求不混用真人皮肤与模特术语。

## 6. 全部默认也不解除明确暂停

```text
2B，参数默认，但先给我汇总，等我确认再生图。
```

只给汇总并等待。之后“可以，开始生成”表示解除这次明确暂停，使用已有配置生图；不要再启动整轮问卷。

## 7. 中途修改与不扩展场景

已设置 n=4、便利店门口、黑风衣、手拿饮料、轻微微笑、85mm。用户说：

```text
改成书店门口，服装、动作、表情和镜头不变。
```

保留明确要求不变的设置，将前景与光线按新环境调整推荐；确有冲突时只问冲突项。不能自动切换成书店员工制服或读书动作。

## 8. 小数量与拼版

```text
原创成年角色，28岁，银白短发、蓝眼睛、黑色风衣。n=2，发现镜头=50%，layout=contact-sheet，其余默认并生成。
```

汇总为 1/2 张注意到镜头，两张独立图片加一张 2×1 拼版。先生成并检查两张单图，再排版；不能让图像模型一次生成双格图来替代两张原图。

`n=10 layout=contact-sheet` 则采用 4×3，末行现有图居中，空位保留背景，不复制图补满十二格。

## 9. 身份含糊与内容冲突

同名角色无法确定作品时，即使用户说“默认生成”，也先询问所指作品，不猜测身份。

用户指定私密场景时，保留角色、服装等有效选择，提供公开空间替代并等待选择；不会把替代场景说成用户已选。真实人物姓名或真人照片则不进入本技能模板。

## 10. 工具限制与部分完成

没有生图工具：完成参数汇总，明确图片尚未生成，可交付完整提示词，但不把它视作图片任务已完成。

计划四张，第一、二张成功，第三张工具报错：若是工具明确允许重试的临时错误，可对第三张额外尝试一次；错误无法就地解决或重试仍失败时，展示两张已完成图片，说明第三张失败及第四张尚未生成，保留配置和首图参考。后续恢复从第三张开始，不重做前两张，不声称四张全部完成，不无限重试。

全部单图已生成但没有可用排版能力：交付单图，明确拼版仍未完成。图片内容正确但用户要求修改颜色时，优先以已有图进行局部编辑，不重启角色选择。

## 11. 真人写实程度需要选择，二次元跳过

用户在画风问题后说“真人 COS”，接下来询问纪实自然（推荐）/自然写真/商业精修，不能把推荐的纪实自然直接当作已选。若用户说“二次元”，则跳过这个真人限定项，不把毛孔或真实皮肤写入请求。

## 12. 把不真实感的复盘变成具体生成条件

用户已经选定虚构角色与服装，继续说：

```text
想要真实抓拍，在书店取书，不要每张都像站着摆拍。其余默认生成。
```

助手记录真人纪实自然，动作限定为取书过程。多张可在允许范围内选择手刚碰到书脊、抽出书、转身抱书等阶段，并写清身体重心、手部任务和视线；不能全变成腿交叠、手放腰间的同一站姿。

光线来自书店顶灯与门窗，允许脸部一侧处于阴影；衬衫在抬臂处出现合理受力褶皱。书架可实际挡住一部分肩膀或包，保留足够角色特征。背景应有可辨层次，与人物共享色温、锐度过渡和阴影关系，而不是人物锐利地贴在均匀糊掉的布景上。

引用已验证的角色图时明确只保持脸、头发、服装与角色符号，本张按新的取书阶段安排动作和构图。不要擅自添加脏污、疲态、明显衰老或强噪点。

若用户同时要求“全身完整、服装全部可见”，则保留该要求，将遮挡放到不影响展示的位置，通过动作和环境光增强真实感，不能为了真实而裁掉鞋。

## 13. 参考图的用途不清时先问

用户提供已确认为虚构角色的参考图，只说“按这个来”。若无法从上下文判断是否连姿势和场景也需复制，先询问参考范围：保留人物与服装（推荐）/连构图姿势一起复刻/自定义。明确选择身份参考后，后续不自动锁死站姿和面部补光；用户明确复刻姿势时则尊重该选择。
