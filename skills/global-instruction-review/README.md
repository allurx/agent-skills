# 全局协作指令提炼与复核

从历史会话中寻找有长期复用价值的协作经验，结合现有规则判断是否需要调整全局指令。适用于首次提炼、接续审查、复核重复问题和评估规则变化，默认交付有证据的候选报告。

## 安装

无需构建，安装源为完整 `skills/global-instruction-review/` 目录。按[仓库安装与更新说明](https://github.com/allurx/agent-skills#安装)选择目标位置，并保留整个目录。

## 使用

```text
使用 $global-instruction-review 从历史协作中提炼并复核全局指令，核实覆盖范围并交付候选修改清单，不修改文件。
```

如已知道上次提炼记录、维护源位置或希望覆盖的历史来源，可一并提供；也可以指定时间范围和报告时区。未提供时，Skill 会从当前可访问资料中定位，并说明无法确认或读取的部分。时区选择见 [审查范围与时区规则](SKILL.md#确定审查范围)。

报告先列最终候选，再逐项给出来源、当前条款、完整候选文本、收益、代价和验证方式，同时标明报告时区，说明主要未采纳项及实际覆盖与缺口。现有规则已经足够或证据不足时，可以没有候选修改；已识别的执行问题仍需交代诊断依据、具体改进、验收方式和未解决部分。

历史访问取决于宿主提供的工具和材料，Skill 本身不提供额外访问能力。单纯查询历史、讨论提示词或整理已有指令层级不属于本 Skill 的提炼任务；结构整理可使用 `instruction-structurer`，无需将它作为本 Skill 的运行依赖。

候选报告不自动授权修改维护源、同步生效文件、保存记录或执行 Git 操作；另有明确授权时按其范围处理。此 Skill 不自动定时运行。完整判断方法见 [SKILL.md](SKILL.md)。
