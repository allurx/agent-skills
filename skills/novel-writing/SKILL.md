# 小说创作与修订

以可读、有辨识度且能够持续发展的小说为交付目标。用户委托创作时，默认 AI 主笔并承担必要审查，用户按约定读稿反馈；不因用户是写作新手就要求其亲自练笔。方法服务于具体人物、故事和阅读体验；保留不同风格的选择空间。

## 确定任务对象与所需资料

本 Skill 为全局方法，不绑定工程、题材或作品。先根据当前请求和有效上下文识别对象：一般写作讨论、某个候选故事，或已有作品。不要把工作目录、旧记忆或曾出现的书名当作默认创作对象，也不要串用不同作品的设定。

有适用的项目约定时按其资料入口工作；资料也可以直接来自当前对话或附件，不要求先建立工程。按实际任务读取：

- 创作、续写与实质改稿：取得相应作品的创作要求、当前状态、目标正文、必要前情及已采用的计划。摘要用于定位，关键规则、承诺和知情范围回查原文；文件名与结构服从现有组织，不要求固定的“创作约定”或“创作档案”文件。
- 局部校对：读取目标段及足以判断语境的上下文，出现影响前后关系的问题时再扩大范围。
- 故事设计或整体审阅：读取所涉人物、阶段计划、正文与未兑现承诺。未提供的全本不能当成已读。
- 一般创作讨论：直接分析所问问题和取舍；没有具体作品时，不要求先交书名、大纲或人物表，不擅自建立故事或写入作品资料。

分清用户决定、候选计划、工作稿事实和已确认正文。工作稿尚未定案仍需内部一致。未确定剧透偏好时，不主动展开具体作品的远期谜底；一般创作讨论不为此增加前置问题。现实事实、合理推测与虚构规则分别处理；所需事实查证围绕剧情真实依赖展开，不要求每章重新联网调研。

## 按请求选择工作方式

| 任务 | 应交付的结果 |
|---|---|
| 讨论或规划 | 针对所问范围提出人物目标、冲突、重要选择及其后果；比较有实质差异的方案。未决定内容标为候选，按用户的剧透约定展示，不顺带改正文 |
| 写作或续写 | 在授权范围内完成章节或指定片段，让人物选择与事件结果推动故事；承接已写状态，提供本段应有的体验和变化 |
| 修订 | 从反馈定位原因与影响范围，保留仍有效的情节、人物特征及用户喜欢的部分；完成相关修改并回看前后衔接 |
| 审阅或诊断 | 结合文本位置说明读者可能遇到的问题、依据和改法；区分事实错误、设计取舍与口味，未要求改稿时保持只读 |
| 校对 | 处理字词、标点、指代、称谓和格式等指定问题；不以校对为由改变故事或重写全部文风 |

以当前请求和持续有效的约定判断范围；既有待反馈状态不抵消用户本次明确的续写或修改要求。能从资料合理确定的细节自行处理，真正影响方向且无依据的信息再澄清；不要把所有待定事项一次性抛给用户。

## 形成正文与选择手法

先判断当场跟随谁、他想做什么，以及读者需要理解、感受或期待什么，再决定怎样展开。该判断用于写作，不要求把内部分析逐项展示给用户。

- 让重要人物依据其经历、信息、欲望与限制行动，并承担后果。关系影响选择、信任与资源；对手和配角有自己的立场，不靠临时降智抬高主角。
- 推进可以来自能力、认知、关系、处境或责任的变化。探索与新舞台应带来新的问题和体验，既有成果、人物和代价继续产生影响。
- 按用途选择视角、叙述距离、场景与概述、信息顺序、动作空间、细节、意象、对白、心理及句段节奏。让决定解法的因果清楚，同时保留情绪、生活质感与画面。
- 同时安排期待、推进、兑现和余波。章末可以是决定、发现、成果或情绪落点；不强制固定章长、反转频率、爽点数量、短句比例或悬断位置。
- 长线设计按风险细化：核心矛盾、关键真相和规则需要能相互支撑，远期普通细节保留调整空间。结局回应主要冲突与承诺，不用临时增设规则或无限换地图延长故事。

读者说“吃力、拖、无感”时，检查具体的理解负担、信息时机、人物动机、情感准备和推进。反馈是体验证据，具体改法仍需判断；不能自动推成禁细节、删日常或固定某种文风。用户给出的作者和段落是比较入口，调研范围按实际问题决定，不机械模仿某位作者。

## 按需使用研究

处理结构、人物、阅读负担或方法取舍时，按问题参看 [创作判断参考](references/craft-guide.md)。通用方法在该文件集中维护；需要核对作者经验、正文样本、查阅日期或证据边界时，再读 [研究来源与作品样本](references/research-sources.md)。这些资料保留不同手法的条件，不是逐项必填表，也不要求每次全文加载。

当前任务已有相关研究时优先复用并核对适用性；需要新依据时比较跨作者、跨题材的可靠材料。区分作者自述、局部文本观察、语言规范与综合建议，不把名作的个别做法当通则，不把片段抽样外推为全本验证。资料不足不等于必须停止一般讨论；说明判断依据和边界。

## 修订、核对与交付

实质改稿前确认可恢复的原稿；已有相同历史版本可复用，不为每次微小校对新增备份。需要备份时沿用作品已有的历史版本位置；没有约定时选择不混入当前正文的清晰位置并标明版本，写入前复核目标未被并发修改。

完成正文后按任务尺度复查：

- 单章或片段：因果、人物动机与知情范围、能力与资源限制，以及信息、空间、情感和语言是否共同支持目标体验。
- 阶段或完整作品：检查重复、人物与关系变化、成长探索、承诺兑现、主题及收束；整章检查不能替代跨章阅读。
- 修改涉及共享事实时回查相关前文；超出授权范围的修改提出影响和建议，不静默改动无关或已发布内容。

有持久化任务时，只同步本次确实改变的事实、未决事项和稿件状态；拟议情节留在计划，不能记成已发生。遵循用户指定的格式和资料归属，本地正文与人工维护记录默认使用 UTF-8 Markdown，工具配置与原始机器数据保留适用格式，其他交付格式按目标需求导出。仅要求对话回答时直接回答，不自动建文件，也不因讨论形成建议就修改本 Skill。正文内不混入审稿批注、质量评分、来源清单或工作过程。

交付完整章节或用户指定范围的成品，附必要的变化和未决事项；不要求用户填写专业审稿表。保存成功、逻辑自洽、独立模型审查和用户满意分别报告。实际阅读效果仍需试读，不能以用了 Skill 或检查通过承诺顶级文学质量。
