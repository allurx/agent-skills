# 创作判断参考

这是供规划、写作、修订与审阅按需使用的判断工具，依据跨类型作者访谈、公开原作样本与专业写作材料整理。没有指定作品、题材或必须采用的文风，也不要求每一场景同时承担全部作用。

## 故事与长篇发展

- 先明确读者在跟随谁、期待什么。吸引力可以来自目标、处境、关系、规则、生活经验或叙述声音；开篇不必一律安排生死危机。
- 让人物依据其经历、欲望、信息和约束作选择，结果改变后续处境。成长可以是能力、认识、关系或责任；配角和对手也有独立目标。
- 回报既包括胜负和发现，也包括被理解、关系变化、情绪释放、生活质感和审美体验。高潮需要积累与余波，提前刺激可能透支后续。
- 检查新阶段是否改变问题、解法或人物关系。换地图、升级和揭谜本身不保证新鲜，旧人物、成果与代价应继续产生影响。
- 规划按因果风险细化；核心规则、关键真相与终局问题需能相互支撑，不以大纲长度证明质量。主线已完成、延长只剩重复时，允许结束。
- 主题通过选择与后果体现。结局处理主要冲突、人物变化及郑重提出的承诺；不要求每个生活细节都是伏笔，也不能用开放结局掩盖未完成主线。

比较依据：[猫腻对高潮与节奏的反省](https://www.thepaper.cn/newsDetail_forward_30300822)、[priest对反转、补洞与人物关系的反省](https://image.chinawriter.com.cn/n1/2020/0706/c404024-31771919.html)、[乌贼对升级与神秘感的反省](https://image.chinawriter.com.cn/n1/2020/0630/c404024-31765475.html)、[蝴蝶蓝谈人物与结束时机](https://www.thepaper.cn/newsDetail_forward_3556343)。这些是作者经验，不是成功的因果证明。

## 从阅读反馈定位表达问题

| 观察角度 | 应判断什么 |
|---|---|
| 视角、距离与声音 | 谁观察、知道多少，何时靠近体验或拉远概述，切换能否跟上 |
| 信息顺序 | 理解当下目标和选择的必要信息是否及时出现；未揭晓的是真相还是基本行动信息 |
| 场景与概述 | 关键选择是否值得展开，重复过程是否可以概述；不机械禁用任何一种 |
| 动作与空间 | 谁做了什么、为何奏效，关键物件是否已建立；不必逐帧交代运动 |
| 细节、感官与意象 | 是否提供人物、环境、情绪、理解或生活体验；重复意象是否获得新意义 |
| 对白与潜台词 | 人物此刻想得到什么，语气是否符合关系，读者能否推知未说出口的意思 |
| 心理与情感 | 触发、判断与行动是否相接，是否贴标签或重复解释同一情绪 |
| 词句、段落与转场 | 用词、指代、句法是否清楚；长短句与分段是否服务效果，时间地点变化是否可辨 |
| 设定与专业说明 | 此刻需要名称、用途、限制还是完整原理；不能把研究笔记直接塞入正文 |
| 风格与校对 | 叙述与人物的语域是否相称，字词、称谓及标点是否准确；不把规范与审美偏好混同 |

“读着累”可能来自信息时机、概念数量、空间关系或情感准备，而非细节本身。修订应针对原因；不能自动改成全部短句、删光描写、每段固定行数或每章硬断悬念。

参考：[对白、动作与描写如何配合](https://writingexcuses.com/writing-excuses-8-31-combining-dialogue-blocking-and-description/)、[潜台词的上下文条件](https://writingexcuses.com/17-34-developing-subtext/)、[职业细节与阅读体验的平衡](https://www.chinawriter.com.cn/n1/2022/1128/c404024-32575821.html)。外语句法与课堂练习配额不直接移作中文规则。

## 根据所需感受选择手法

- 清晰爽利：突出目标、行动和后果，减少同时待处理的信息，同时保留解法因果。
- 震撼与惊奇：先有尺度、边界和参照，再让发现改变认识，不只堆强度词。
- 恐惧与悬疑：让证据逐步改变解释；真相可以难辨，当下行动仍应可理解。
- 幽默：利用关系、认知差异和表达节奏，判断笑点是否破坏当前情绪。
- 温暖、亲密或悲伤：通过已建立的关系、选择与日常变化积累，也允许关键时刻直说。
- 沉浸与生活感：保留特定人物眼中的质感；日常可以自成阅读乐趣，不必全部转为机关。

## 按尺度审阅

单章看理解、人物、实际变化与体验；阶段看重复、关系、探索和回报；全篇看重要承诺、因果、主题与收束。依据文本解释问题，不用统一评分或模板替代判断。

用户的读后感是体验证据，具体改法仍需与整段故事核对。模型自查、结构校验和来源权威不能独立证明好看，也不能保证长期追读或顶级质量。
